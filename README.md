# tablefmt

Excel → AI-readable markdown. Flattens merged cells and multi-level headers
into structured text that LLMs can actually read. Runs entirely in your browser —
nothing is uploaded, your original file is never modified.

**Use it:** https://tery r.github.io/tablefmt/ （replace with final Pages URL）

Built on the header-tree concepts of [Gewu (格物)](https://github.com/TeryR/gewu).
AGPL-3.0. Core engine files: `core.js` (detection + flattening), `index.html` (UI).
